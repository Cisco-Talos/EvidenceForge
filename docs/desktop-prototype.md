# Desktop prototype retired

The Qt prototype was replaced by EvidenceForge Studio after core-parity acceptance on
October 2, 2026. Use `uv run eforge-desktop` with the
[Studio source-run setup](studio-source-run.md). `eforge-studio` remains an equivalent alias.

Authored scenarios and bundles remain usable. Old prototype state files are not deleted or
imported automatically. The headless CLI job controller remains shared infrastructure; it
has no Qt dependency.
