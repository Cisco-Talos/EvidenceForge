## PR CI repair

[PR #447](https://github.com/Cisco-Talos/EvidenceForge/pull/447) initially tested head `748b01f2`
in [CI run 38340926440](https://github.com/Cisco-Talos/EvidenceForge/actions/runs/38340926440).
Lint's generation-behavior guard and native Windows generation both rejected the stale declared
surface digest after the metadata-cache registration changed `config/provider.py`. The behavior
manifest now records revision 163 with impact none and the matching digest; the change owns cache
admission/cleanup only and leaves equivalent resolved inputs and deterministic rendering unchanged.
The Windows runner also masked its retained failure report with a CP1252 console encoding error.
Its diagnostic driver now emits UTF-8 and gives pytest the same explicit encoding. Automated
checkpoint/generation and manifest checks verify the repair before updating the PR. Repair commit
`6a43f56c` passes 90 manifest/captured-source/release-pipeline cases, two complete checkpoint CLI
generation/suspend/resume cases, and a regression that reproduces a Unicode failure report under
a legacy console encoding while preserving the child exit code. The initial native Windows
artifact confirms that its primary failure was the stale behavior digest, independent of the
encoding error. The manifest guard against dev, Ruff and whitespace checks pass.

The next CI run, `38341753098` on `536f3065`, passed lint, Windows checkpoint durability and
state recovery on all three Studio hosts. Native chat permission probes on both Linux runners
then failed even for their required positive read, with `bwrap: loopback: Failed RTM_NEWADDR:
Operation not permitted`. The disposable runners lacked the Ubuntu application-specific
bubblewrap AppArmor profile already used successfully on the user's Linux VM. CI now installs
Ubuntu's apparmor-profiles/apparmor-utils packages and loads its unmodified bwrap-userns-restrict
profile before those probes. No Studio permission boundary or native assertion is relaxed, and
Ubuntu's global unprivileged-user-namespace restriction is retained.
