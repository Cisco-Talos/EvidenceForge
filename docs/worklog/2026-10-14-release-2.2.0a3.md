shell contract cases. macOS also passed isolated packaged CLI/resources checks. All four slow
shards passed (508, 456, 462 and 517 cases respectively; five platform-dependent skips overall).

`test_project_pack_requires_explicit_override_when_scenario_is_elsewhere`. The publication

Linux coverage was still running when this correction was prepared. No installers or release
assets have been created.
