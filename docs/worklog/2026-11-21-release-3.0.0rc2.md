## Northstar reproduction

`evidenceforge/northstar-stolen-credentials@1.0.0` failed locally on the tagged commit
with the same two factual disagreements and six unexpected source expectations.
Evaluation's aggregate acceptance passed. The shipping-example test requires zero
ground-truth disagreements.

All eight findings concern six canonical Samba SMB logoffs on `NSH-SAMBA-01`
under `approved-admin-rdp`. The syslog expectation requires the username.
For example, the `21:34:27.366259Z` logoff aligns exactly with the native
`smbd` line `closed connection to service ClinicalArchive`, which carries the share
and worker PID. Earlier file audit rows carry the username. Check the source-native
ground-truth requirement for the Samba close and verify that matching distinguishes
the close from nearby file or authentication rows.

Preserve the annotated rc2 tag. A source fix for the reproduced regression requires
a new release snapshot.
