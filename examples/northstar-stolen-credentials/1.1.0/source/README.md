# Northstar Health - Stolen Credentials

Investigate stolen IT credentials, a blocked RDP attempt, and the scope of compromise. Compare the incident with routine clinical SMB access and authorized WinRM traffic.

Planned size is **7 accounts, 11 systems, and 8 collection hours**, plus one hour of warmup.

- ENVIRONMENT.md is the analyst handout.
- INSTRUCTOR_GUIDE.md contains the questions, intended timeline, answers and limits.
- RESEARCH.md records the technique basis and composition.
- scenario.yaml is the deterministic authored input and contains the solution.

This Schema 3 draft uses the workspace's published Northstar Health 1.2.0 organization pack. Retain the draft metadata and configuration alongside the source. Keep generated bundles outside this source directory. The scenario uses the default rendering target.
