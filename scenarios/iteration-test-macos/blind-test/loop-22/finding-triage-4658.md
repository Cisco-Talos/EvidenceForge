# Event4658 field erratum

The proposed removal of ProcessName is rejected. Microsoft's Event4658 documentation shows Version0 XML containing ProcessName and describes the field. Preserve this valid source-native field. The original blind report and historical scores remain unchanged for reproducibility; this finding is excluded from future product-fix priorities.

Source: https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-10/security/threat-protection/auditing/event-4658
