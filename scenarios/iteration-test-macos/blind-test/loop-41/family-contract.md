# Successful mounted SMB helper completion

Classification: sibling_defect; adapter_to_family_model. Owner: SMB operation completion intent, delegated to the existing canonical Mac process termination contract. Operation-lived Mac helpers already publish exact fork/exec identities, but their completed SMB owner discards its modeled successful terminal result and emits only an unknown-result close. A naturally completed all-success bounded operation now carries an explicit nominal exit0 plus the exact live execution identity into the shared termination service. This is declared synthetic operation truth, not an inference from successful exec or an arbitrary success default. Both persistent and legacy operation completion paths use the same eligibility helper. Resident/reused explicit actors, failed/mixed/unknown operations, session-truncated/out-of-window closes remain uncertified. Native ES, eCAR, State and lifecycle consume one terminal fact; emitters do not invent outcomes. Tests must cover success/read/write/list and failed/sibling behavior, native identity/census and recovery-compatible exact process binding. Risk: model-owned nominal outcomes are not measured application results; no failed status is guessed.
