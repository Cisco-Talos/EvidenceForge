# One actual client User-Agent per canonical HTTP request

Classification: sibling_defect / shared request truth. Threat54/55 and Network54 independently reproduce57–59 apparent client-side HTTP/proxy User-Agent disagreements. Owner: network transaction planner's process attribution adapter and proxy request construction. The proxy action freezes a request header before budgeting its wire bytes and channel affinity; a nested client-leg network planner must not select it again. Browser-process defaults remain available before that freeze. Request headers can intentionally differ from installed browser inventory, including command-line spoofing and application-specific service agents.

Invariant: Process binding cannot replace a bundle-finalized canonical HTTP User-Agent or known absence. Before the action freezes it, existing process-bound browser defaults remain available. Explicit proxy bundle must pass its finalized request header unchanged to the client-leg network planner; transparent proxy evidence must use the same HTTP header rather than independently applying domain policy after HTTP context exists. Preserve process attribution, request byte budget, CONNECT channel affinity and explicit command intent. Never change an emitter or derive values from rendered proxy rows.

Entry paths: explicit proxy setup and inspected children, direct HTTP, automatic transparent proxy, service application agents, command-line curl/wget/custom -A, known-absent headers and unspecified browser defaults. Tests cover default versus selected versus known-absent and transparent/sibling paths. Fresh probe uniquely joins client, second, method and complete target with qualifications, deduplicates sensor copies and checks all repeated disagreements. Do not interpret User-Agent as a guarantee of executable identity.

Design correction: broad preservation of every nonempty incoming browser hint broke two existing process-version contracts. Narrowed the repair to the actual ownership boundary: a supplied ProxyContext marks a bundle-finalized header. Existing browser defaults before bundle preparation remain tested. Explicit browser spoofing provenance is not newly modeled by this loop.
