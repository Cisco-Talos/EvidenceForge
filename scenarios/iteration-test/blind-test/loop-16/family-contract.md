# Automatic SMB task/file eligibility

Selected family: sibling_defect/distribution_texture, repeated Host/Detection/Threat
observations of automatic Mac cat reads of PDF/Office files and tee writes to DOCX.
These calls are technically valid; the defect is the ordinary task population,
not a claim that byte streaming is impossible. Explicit authored binary actions
remain valid and unchanged.

Owning layers: data-driven SMB operation-process profile and baseline task planner,
with a pure admission adapter on SmbActivityActionBundle. The bundle must reuse one
operation-profile resolver for admission and actual persistent client execution,
including exact platform/services/system-type/access-mode and scope key. No new
source renderer or native GUI application is introduced.

Invariant: ordinary automatic baseline tasks select files matching their configured
operation tool's task extension policy. Selector criteria remain AND-combined.
Eligible shares are filtered before preference/random choice; when no eligible task exists it is
skipped before State/temporal preparation, with no network-only substitute. Explicit
path/ref, authored storyline, batch and supplied-file/transfer intent remain
unchanged. Missing new optional metadata preserves old frozen behavior.

Entry inventory: shared baseline SMB prepass (Mac/Linux/Windows when enabled),
Windows-only inline baseline producer, ActivityGenerator prepare/generate entry,
SmbActivityActionBundle persistent process preparation, composite transfer legs,
explicit storyline and raw/rendered source paths. Admission applies only ordinary
baseline auto-target tasks; it is not a new restriction in generic prepare().

Consumers: ES argv/process/file evidence, eCAR files/process/flows, server-native
Security/Samba audits, Zeek SMB/file/transport, prepared action replay/checkpoints.
Central tests cover selector intersection/empty set, exact profile resolution,
share choice among eligible candidates, no mutation on skip, old metadata absence,
explicit binary action and Windows/direct/copy siblings. Config validator and
reference documentation must recognize the optional task metadata.

Risks: empty extensions means unrestricted in existing selectors, so empty
intersection must return None. Mapping admission must reuse exact audience rules.
Availability is a read-only State lookup. No new RNG stream, identity allocation,
cache or retention ceiling; preserve current prepared/execution ownership.

Deferred: purpose-aware Windows policy repository layout; native Mac audit-token
and installed-inode population (need stronger native semantics). No scenario or
reviewer-instruction changes. Source15 remains frozen through generation+post.
