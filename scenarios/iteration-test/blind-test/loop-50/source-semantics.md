# Native ICMP projection

Pinned [Zeek8.0.5 connection logger](https://github.com/zeek/zeek/blob/v8.0.5/scripts/base/protocols/conn/main.zeek) returnsOTH for non-TCP/non-UDP and includes history only when populated. The [ICMP analyzer](https://github.com/zeek/zeek/blob/v8.0.5/src/packet_analysis/protocol/icmp/ICMP.cc), [ICMP session adapter](https://github.com/zeek/zeek/blob/v8.0.5/src/packet_analysis/protocol/icmp/ICMPSessionAdapter.cc), [IP session adapter](https://github.com/zeek/zeek/blob/v8.0.5/src/packet_analysis/protocol/ip/SessionAdapter.cc) and [Conn implementation](https://github.com/zeek/zeek/blob/v8.0.5/src/Conn.cc) do not invent data history for ICMP. In contrast [UDP analyzer](https://github.com/zeek/zeek/blob/v8.0.5/src/packet_analysis/protocol/udp/UDP.cc) explicitly addsD/d. ConnSize counts packets without adding data history. ICMP example records in the upstream tunnel-log guide omit history. Source state/history mapping is shared by direct typed and frozen sensor projections; canonical request/reply facts and raw escape hatches are preserved. Exact pinned SHAs are retained in family-contract.md.
