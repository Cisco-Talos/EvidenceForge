- **Runtime versus observed lifetime:** Normal vmstat semantics make the two short runs useful diagnostics, but no successful-completion assertion is present. The four near-900-second Windows lifetimes may reflect policy. The responses reject both broad lifetime inflation and an unsupported shared cause across those observations.

## Improvement Recommendations (Consensus)

These are conditional priorities supported by all or most written responses, not a negotiated commitment or proof that repair is required. All four support the curl, finite-command, timeout-policy and native-semantics priorities. Hunter, Detection and Network recommend the TLS workload/policy check. SMB handling is a shared diagnostic priority in the hunter, network and host responses and Detection's original report.

- **Bind curl header defaults to executable/configuration state.** If synthetic, keep the two WS-LNGUYEN-01 activity paths coherent with the intended host version and request-header configuration. Preserve intentional changes without requiring extra logs that the represented collection would not capture.
- **Model finite sampling semantics and interruptions explicitly.** If synthetic, assign uninterrupted `vmstat 1 5` execution an appropriate interval/count lifetime. For early termination, preserve cancellation, signal or exit status when the intended source supports it; do not describe a status-free termination as successful completion or lengthen every command.
- **Check the four near-900-second workers against intended timeout policy.** Retain a legitimate scheduler or idle boundary. If no such policy is intended, examine a possible shared default and use activity-appropriate lifetimes; arbitrary jitter alone would not establish realism.
- **Evaluate TLS persistence against represented requests and proxy behavior.** Retain short connections and add persistent transports only where application and policy semantics support them. No response justifies imposing a long-session quota from SNI names alone.
- **Preserve the existing native distinctions.** Keep unlock separate from new logon, fork separate from exec, privilege transition separate from invocation, and transport opening separate from authentication/session readiness and effects. Retain source-specific timing and intelligible causal identity links.
- **Diagnose the specific SMB export orphan.** Examine filtering/loss and connection-summary handling for UID `C5PgTblRidxF4DQCi8`, incorporating the visible client's pre-window-end termination. Document the collection condition where appropriate; do not invent a closed flow merely to force reference completeness.

The written responses support no mandatory additional source volume, extra event-family quota, invented attack mistakes or alteration of storyline completeness.
