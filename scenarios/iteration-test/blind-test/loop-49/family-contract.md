# Loop49 contract: observed TCP history is a physical packet budget

Target Network47's13 conservative loss-marked packet/history contradictions, reproduced identically in46–48. Broader source branch analysis supplies a stronger lower bound, but conservative13 is sufficient. Classification family_level: sensor capture selection and typed observation admission own the physical ledger; history strings are not to be edited just to hide missing packets.

Invariant: each recorded distinct TCP SYN/SYNACK, pure ACK, data, FIN, RST and exclusive multi-flag category requires a retained packet in its direction. Native update_history branches are mutually exclusive for those categories. Ignore ancillary checksum/retransmission/gap annotations in this lower bound. Partial loss must partition canonical payload/packet/IP/header budgets while retaining enough actual packets to support the preserved observed history. If no whole-packet loss partition can meet the bound, do not fabricate a gap. Keep full-wire sequence extent separate from captured content and never recover file bytes from it.

Owner: shared history-to-minimum helper in canonical network semantics, source-observation capture-loss planner, and typed sensor observation admission. Entry paths: ordinary baseline/storyline/causal TCP, browser/proxy/SSH/RDP/database transports, direct typed observation construction/replace, persistent SMB scalar preflight/final rebind. Consumers: Zeek history/count/IP/gap fields, stream extents, extracted files/HTTP, ASA/eCAR captured views, persistent proofs and checkpoint decode. No hostname/UID-specific logic, source-local counter inflation, global perfect capture or raw-record rewriting.

Inventory: ordinary planner has one `_observed_traffic` caller; it invokes the shared directional packet partition. Persistent channels materialize/rebind supplied authoritative ledgers and have separate scalar/final-history validation. Both must use the invariant. Preserve unknown/raw empty histories and non-TCP datagrams. Typed observations with explicit impossible history/counts should fail early; versioned codec rejection remains fail-closed without adding fields.

Risk: medium–high; small flows may no longer support a full-packet gap while preserving all control/history categories, so their capture stays intact. Larger flows retain genuine partial loss. Tests cover both directions, reset/partial/multi-flag histories, loss/nonloss, physical/header partitions, direct invalid observations and persistent admission/rebind. Recheck previously repaired stream extent, analyzer loss, ASA and complete native Mac coverage.

Primary pinned source: Zeek8.0.5 TCPSessionAdapter.cc `update_history`, SHA716fcfd4e195620d756ea7be7e0190dadd8a042b. SYN/FIN/RST/multi-flag branches exclude the pure ACK/data branch.
