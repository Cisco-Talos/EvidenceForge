# Loop 40 Deliberation Summary

The reviewers reconsidered only the four Loop 40 blind reports. Initial scores
were 26/52/63/66 (average 51.75) with Real/Inconclusive/Synthetic/Synthetic
verdicts. Final scores were 64/68/69/74 (average 68.75), unanimously Synthetic.

The panel agreed that the strongest production-like properties remain lifecycle
ordering, source-native schemas, process and UID correlation, TLS/certificate
loss semantics, and the cross-source attack chain. Consensus shifted because
three independent current-data patterns survived cross-examination: fabricated-
looking CBS package inventories and actors, 13 repeated browser/Outlook-to-SSH
parent relationships, and a near-flat three-value UFW TCP-window population.

The panel reduced the weight of the post-cutoff Zeek-duration claim: because
Zeek `ts` represents connection start, a start-time-bounded extract can retain a
later close while a timestamp-bounded ASA extract omits the teardown. It also
rejected narrow Security/Sysmon timing jitter as synthetic evidence after peers
described the offsets as credible source variation.
